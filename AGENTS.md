# Reglas del proyecto

- **NUNCA commitear ni hacer push salvo pedido explícito del usuario.** El usuario
  realiza los commits/push él mismo para evitar rollbacks. Ante un commit pedido o
  sugerido, detenerse y consultar; solo proceder si el usuario lo ordena explícitamente.
- Al terminar una tarea de código, verificar con los tests existentes antes de finalizar.
